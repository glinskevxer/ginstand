# ginstand

Office records for a custom cotton gin. Seed cotton arrives as modules, gets
ginned into bales, the bales get classed and valued, and the producer gets a
settlement statement.

The gin does not own the cotton. It charges for ginning, deals with the seed,
and hands the lint back. Most of the work in here is keeping straight whose
cotton is in which bale once a gin run has mixed four growers together.
